1. Executive Summary & Problem Formulation

The India Meteorological Department (IMD) and numerical forecasting centers produce rich, highly granular atmospheric forecasts. However, for farmers in rural hinterlands, inter-city highway travelers, and municipal disaster responders, raw numerical metrics (e.g. 28.5°C, 82% humidity, WMO code 65, 12 knot gusts) are cryptic and lack actionable clarity.

WeatherGPT bridges this critical "last-mile" dissemination bottleneck by providing an authoritative, conversational AI layer that interprets verified Numerical Weather Prediction (NWP) forecasts into native linguistic advisories (Hindi, Hinglish, English) while enforcing strict Zero-Hallucination Grounding.

Core Architectural Axiom: The AI model never invents, guesses, or speculates on meteorological numbers. Forecast retrieval is strictly segregated from conversational narration.

4. Backend Module & Service Architecture

🤖 AI & Query Parsing Engine (ai_service.py)

Classifies dialog intent into weather, greeting, identity, or off_topic. Implements safety guardrails that politely decline queries on cricket, cinema, or coding, redirecting users back to live weather metrics. Automatically infers domain personas when agricultural or travel keywords are detected.

🌤️ Weather & NWP Engine (weather_service.py)

Extracts real-time metrics, hourly forecasts (24 points), and 7-day trends. Decodes 20+ WMO atmospheric codes into visual icons and descriptions. Compares ECMWF, GFS, and ICON forecasts to generate model consensus summaries. Includes offline synthetic data fallback.

🚨 Alert Evaluation Engine (alert_service.py)

Evaluates IMD CAP rules: Red Alert for extreme heat (≥42°C); Orange Alert for heavy rainfall (>25mm) and high winds (>45 km/h); Yellow Watch for lightning storms. Maintains simulated CAP bulletins for Mumbai, Indore, and Delhi.

🌾 Domain Advisory Engine (advisory_engine.py)

Computes actionable guidance: advises farmers to halt pesticide spraying and delay irrigation if rain probability exceeds 50%; warns motorists about hydroplaning and wet road braking buffers; alerts citizens about UV index protection and umbrella need.

5. Frontend Dashboard & User Interaction Console

The user interface (frontend/index.html) is constructed as a dual-column command console optimized for both desktop and mobile viewports:

💬 Left Column: Conversational Console

  • Speech-to-Text (STT): Native microphone input recognizing Hindi and Indian English.
  • Text-to-Speech (TTS): 🔊 Listen button for spoken narration of every response.
  • Grounding Transparency Inspector: Expandable details element showing meteorological grid coordinates, verified data feeds, and DPDP Act 2023 compliance.
  • Client-Side Resilient Fallback: If backend is offline, frontend queries Open-Meteo directly and formulates responses in the browser.

📊 Right Column: Multi-Tab Intelligence Console

  • Live Metrics Hero Card: Temperature, apparent heat index, wind, humidity, UV index, and AQI.
  • 24-Hour Risk Timeline Ribbon: Visual color-coded hourly danger window (Green / Yellow / Red).
  • Interactive Persona Panels: Dynamic metrics for Kisan (soil moisture, spray window), Yatri (corridor score, fog), and Disaster Officer (SDRF readiness).
  • Doppler Radar Tab: Leaflet map streaming live precipitation tiles from RainViewer.
  • NWP Model Comparison: Cards showing ECMWF vs GFS vs ICON forecasts.
